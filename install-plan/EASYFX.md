# Easy FX — studio usage guide

Pixel particles and effects for 2D games: hit sparks, slashes, explosions, dust, smoke, torches, campfire, rain,
leaves, fireflies, pickups, coins, heals, level-ups, food-stall steam, and a festival set for the multicultural
village (Loy Krathong sky lanterns and krathong glow, Songkran splash, temple/shrine incense, Hari Raya pelita and
fireworks). Agents **pick presets, tweak params and seeds, render and export**. Every pixel is simulated from a seed;
nothing is generated by AI and nothing calls a network.

Install is local only. Do not push or modify the upstream GitHub repo.

## Paths

| What | Path |
|---|---|
| Install (package 0.1.0, `<SHA>` on master) | `/workspace/indie-studio/tools/easyfx` |
| CLI wrapper | `node /workspace/indie-studio/tools/easyfx-cli.mjs` |
| Studio projects | `/workspace/indie-studio/projects/<Name>/` |
| Effect format | `/workspace/indie-studio/tools/easyfx/docs/FORMAT.md` |

The 28 presets are built into the tool and need no files. A game's own effects (`effects/<id>.easyfx.json`), renders
and engine exports belong under `/workspace/indie-studio/projects/<Name>/`.

```bash
export EASYFX_HOME=/workspace/indie-studio/tools/easyfx
export EASYFX_WORKSPACE=/workspace/indie-studio/tools/easyfx
export EASYFX_ALLOWED_DIRS=/workspace/indie-studio/projects
```

The wrapper sets these for you. Effect ids must match `^[a-z0-9_-]+$`. For a game, pass
`--workspace /workspace/indie-studio/projects/<Name>` (init that folder once).

`export --out DIR` (single preset only) **writes into DIR without deleting it**, so files of effects you dropped stay
behind. Use a fresh folder per export, or the default `exports/easyfx-<preset>/`. `--preset all` cannot take `--out`.

## Commands (verified)

```bash
CLI="node /workspace/indie-studio/tools/easyfx-cli.mjs"
OUT=/workspace/indie-studio/projects/<Name>

$CLI init --workspace "$OUT"                     # effects/ exports/ + 3 sample effects
$CLI list --workspace "$OUT"                     # presets + workspace effects (--tag festival, --json)
$CLI show campfire --workspace "$OUT"            # resolved params JSON
$CLI render khom_loi --workspace "$OUT" --scale 3 --out "$OUT/fx-khom_loi.png"
$CLI render campfire --workspace "$OUT" --seed 7 --set count=30 --set '1.ramp=#fff6c8,#ffd86a,#f07f3c' --out "$OUT/fx-campfire-7.png"
$CLI new blue_coins --from coin_burst --set 'ramp=#e8f6ff,#7cc8f0,#2c6aa8' --en "Blue coins" --workspace "$OUT"
$CLI check blue_coins --workspace "$OUT"         # exit 1 on errors (JSON path + message)
$CLI export --workspace "$OUT"                   # exports/easyfx-{godot,pixi,png,json}
$CLI export hit_sparks coin_burst --preset godot --workspace "$OUT" --out "$OUT/exports/fx-godot"
$CLI export --tag festival --preset pixi --workspace "$OUT"
```

Presets: combat `hit_sparks slash_arc explosion_small explosion_big magic_swirl` · ambient `dust_puff footstep_dust
smoke torch_fire campfire embers` · nature `water_splash rain falling_leaves fireflies` · reward `sparkle_shine
coin_burst heal_plus level_up` · food `steam` · festival `confetti lantern_glow khom_loi krathong_glow songkran_splash
incense_smoke pelita_flicker raya_fireworks`. Never invent ids, shapes, emitters or props: take them from `list` /
`workspace_info`.

`--set`: `count=20` (first particle layer), `seed=7`, `frames=24` (top level), `2.ramp=#fff,#f4ae3d` (layer 2),
`0.emitter.x=0.4`, `*.gravity=0` (every layer).

### MCP

```bash
EASYFX_WORKSPACE=/workspace/indie-studio/projects/<Name> EASYFX_ALLOWED_DIRS=/workspace/indie-studio/projects \
  node /workspace/indie-studio/tools/easyfx/dist/mcp/server.js                 # stdio
node /workspace/indie-studio/tools/easyfx/dist/mcp/server.js --http --port 18849   # POST http://127.0.0.1:18849/mcp
```

Tools: `workspace_info` (call first), `list_effects {tag?}`, `get_effect {id}`, `write_effect {id, base?, set?, params?,
th?, en?, dryRun?}`, `render_effect {id, scale?, seed?, set?}` (returns the strip as an image), `export_fx {ids?, tags?,
preset?, out?}`. Flow: `workspace_info` → `write_effect` (dryRun) → `write_effect` → `render_effect` → `export_fx`.

Web editor: `$CLI serve --workspace "$OUT"` (http://127.0.0.1:8848; dev Vite 5180; MCP HTTP 8849). Do not collide
with Easy Scene (8788 / 5174 / 8796), Easy Dialogue (8798 / 5175 / 8799), Easy Tilemap (8808 / 5176 / 8809),
Easy Quest (8818 / 5177 / 8819), Easy SFX (8828 / 5178 / 8829) or Easy UI (8838 / 5179 / 8839).

## Export layout

| Preset | Output |
|---|---|
| `png` | `sheets/<id>.png` + `sheets/<id>.json` (frame rects, ms per frame, anchor, loop) + `easyfx.json` |
| `pixi` | per-effect PixiJS v8 Spritesheet JSON + PNG, `easyfx-pixi.js` (`loadFx(PIXI, "easyfx.json")` → `create(id)`), `index.html` demo |
| `godot` | Godot 4.3+ project: `easyfx/frames/<id>.tres` SpriteFrames, `easyfx/scenes/<id>.tscn` AnimatedSprite2D (one-shots free themselves), `easyfx/particles/<id>.tscn` CPUParticles2D, `easyfx/easyfx.gd` (`EasyFx.spawn(parent, id, pos)`), `main.tscn`, `particles.tscn`, `test_fx.gd` |
| `json` | resolved params |

Godot: copy `easyfx/` into the game, then `EasyFx.spawn(self, "hit_sparks", pos)`; keep textures on nearest filter.
Headless check: `godot --headless --path . --script res://test_fx.gd`. Screenshots under xvfb need
`--rendering-driver opengl3` (Vulkan hangs on this box).

Pixi: `const fx = await loadFx(PIXI, "easyfx.json"); const s = fx.create("coin_burst"); stage.addChild(s); s.play();`.

## Known gaps

- `CPUParticles2D` presets approximate the sheets (same count, lifetime, speed, gravity, spread, ramp and scale curve;
  no wobble, outline, glow, arc or prop layers; drag is approximate). The sheets are the exact pixels. There is no
  `GPUParticles2D` file; convert in the Godot editor.
- Glow halos are dithered: they read best over the game's own background, and look olive on pure black.
