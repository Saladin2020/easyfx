# Easy Suite brand assets

Generated by the Easy Suite brand script (pixel logos, banners, social previews). Same frame, palette and
fonts across all thirteen tools; only the icon and accent colour change. Easy FX uses ember red `#e04a3a`
and a sparkle-burst icon; its banner and social art are real Easy FX frames (campfire, pelita, krathong,
incense, sky lanterns, Raya fireworks) on a night street.

| File | Use |
|---|---|
| `banner-fx.png` (1280×320) | README header |
| `social-fx.png` (1280×640) | GitHub social preview: Settings → General → Social preview → Upload |
| `logo-fx.png` (240×240), `logo-*-96.png` | Tool logos; the `-96` set is used by the suite table |

Fonts in the art: Press Start 2P and Kanit (both SIL OFL 1.1). v2 style: subtle green accent and a light
8-point star (girih) pattern on the teak, cream and gold palette.
